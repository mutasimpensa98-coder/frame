## الجديد في هذه النسخة

- **اسم Frame في كل مكان:**
  - الصور اللي تحفظها من المشغّل صارت تنحفظ في `Pictures/Frame`. الصور القديمة تبقى في مجلدها القديم `Pictures/Frame Glass`.
  - النسخ الاحتياطية صارت تتسمى `frame-backup` و`frame-auto`. النسخ القديمة تنقرا عادي.
  - صفحة المشروع في GitHub صار اسمها `frame`، والروابط القديمة تحوّل لها وحدها.

## طريقة التحديث

- **لو التطبيق عندك:** نزّل ملف الـAPK وافتحه، ثم اختر **تحديث**. لا تحذف التطبيق قبل التحديث.
- **على تلفون جديد:** نزّل ملف الـAPK وثبّته. أول ما يفتح تطلع جولة المميزات، وبعدها يطلب إذن الملفات.
